# 前端专属约定

本仓库对应 `qing1989620/xinxin-frontend`。只在本仓库写前端、交互、样式、前端测试与手机壳代码。

- 不修改兄弟 `backend/` 仓库，不导入其源码，不包含 Python 执行器、数据库迁移或服务器凭据。
- 所有业务数据通过后端 HTTP 接口访问；前端权限控制只改善体验，授权以服务端判断为准。
- 产品需求已确认：工作台首页、独立 Agent 一级入口，具体见 docs/product-spec.md。
- Agent 对话保留一级入口，兼顾桌面、手机软键盘、屏幕阅读器和减少动效模式。
- 产品名 Xinxin，暖白、深灰、每次只使用一种可切换强调色。
- 使用 BadGoods「前端审查助手」审查真实页面；源码检查和浏览器实测分别记录，不假报覆盖。

审查说明见 `docs/audit-plan.md`。
