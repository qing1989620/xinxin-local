# 前端审查计划

指定技能：[BadGoods 前端审查助手](https://github.com/BadbotAI/BadGoods/blob/76d20b19c8b2a6513d1516d42fdcc42a2b8c394f/skills/review-frontend-production/SKILL.md)，版本 0.3.0-beta。

本地参考仓库在工作区 `sources/BadGoods`。这里只保存指向技能的说明，不将未选定开放许可证的技能包复制进产品仓库。

调研阶段已在本地共享文档中保存 myself、lankhub、zhishi 的源码候选发现记录与快速体检。它们不构成本产品的上线审计。

已完成的 quick 范围、发现和实际复验见 [quick-review.md](quick-review.md)。以下清单持续用于后续真实设备和上线验收：

1. 登录、Agent 对话、任务详情、文件、技能和设置的真实页面清单。
2. 手机和桌面布局、软键盘、安全区域、长文本、空态、错误、加载、重试。
3. 聊天发送、断网重连、重复提交、取消、任务审批和文件下载。
4. 键盘导航、焦点恢复、表单标签、对比度、减少动效。
5. 类型检查、生产构建、适用测试与浏览器实测。

审查结果分清：源码事实、实测复现、待验证风险。确认全部产品范围后再决定 full 审查的覆盖分母。
