# 前端审查助手 · 本地快速体检

技能：[BadGoods 前端审查助手](https://github.com/BadbotAI/BadGoods/blob/76d20b19c8b2a6513d1516d42fdcc42a2b8c394f/skills/review-frontend-production/SKILL.md)，0.3.0-beta，quick / implement。没有声称全站逐实例完整审计。

对象为此独立 React 仓库，初始基线 4081ba4。源码、类型/生产构建、API 单元测试和本地浏览器互相核对；浏览器使用隔离验收数据，无真实私人文档或服务器。后端授权由独立后端审查。

发现路由：工作台、Agent、任务、资料、服务器、技能、内容及其文章/合集/相册/诗词/简历、工具、记忆、自动化、设置，以及登录/初始化/连接失败状态。本次优先检查 Agent → 工具 → 任务/交付、手机导航、资料检索和技能选择；内容编辑、服务器与自动化表单以源码及接口验证为主，未宣称全部 UI 状态覆盖。

## 关键发现与处理

| 问题与影响 | 证据、处理和复验 |
| --- | --- |
| P1：切换后端可能携带旧认证；网络不确定时重复创建任务 | API 单测验证切换主机先清认证；提交标识绑定输入、权限、附件和预算，在网络重试/刷新后复用，收到持久化确认后清理 |
| P1：手机任务详情受祖先 transform 影响被裁切 | 真实浏览器复现；页面进入改为透明度动画，紧凑屏使用原生 dialog；图表任务完成、产物列表及刷新后详情已复验 |
| P2：手机导航抽屉背景底栏仍在可访问性树中，跨断点可能保留锁定 | 主区及底栏 inert，抽屉焦点循环、Escape/返回恢复；跨 761px 自动关闭抽屉 |
| P2：长文预览没有后续读取入口，旧请求可覆盖新文件 | 增加按 next_offset 继续读取与文件 ID 失效保护；后端长文尾部检索/分页通过测试，完整超长文 UI 压力测试未覆盖 |
| P2：参考图库只有 8 张且跳转缺少说明；技能元数据英文过长 | 95 张参考支持搜索/结构/代码筛选、分批加载、说明/代码与带目标进入 Agent；隐藏 YAML 元数据，拾景中文摘要，技能库/星图/选择预览分层 |
| P2：旧路由依赖和 UUID 依赖已知漏洞 | 升级 react-router-dom 7.18.4 与兼容 UUID override；锁文件、构建和测试通过，npm audit 本次报告 0 个漏洞 |
| P3：手机面包屑尾部缺标签、模型加载被显示成缺配置、快捷键提示不符 | 恢复当前页标签、区分加载/未配置、展示实际模型名、Ctrl K；手机截图复核 |
| P2：切换后端后旧会话深链接不存在，界面仍保留无效会话 ID | API 错误保留 HTTP 状态；仅对当前会话的 404 自动回到新对话，网络失败保持上下文；生产浏览器复验 |
| P2：刷新执行中的会话时，权限表单未恢复已捕获范围 | 从运行记录恢复只读/工作区/完整、服务器、预算和记忆状态；执行中禁止变更；结束后撤销下一轮记忆勾选。源码和类型核对，服务端范围固定已有回归 |
| P2：PWA 新版本只提示刷新，没有激活等待版本的操作 | 新增顶栏“更新应用”，保存当前编辑后由主人显式激活等待版本并刷新；后台任务仍在服务端，浏览器真实多版本更新未完整覆盖 |

## 真实浏览器证据

- 桌面 1366×900：工作台资源节点、真实统计/七日数据；Agent 本轮授权、预算、过程/交付；真实 DeepSeek 调用 write_file 产生文件。PNG 截图 `agent-desktop.png`。
- 手机尺寸 390×844：对话历史刷新后恢复，过程/交付原生弹窗、正确焦点返回、会话改名/归档、工作台和导航。Agent 的 `documentElement.scrollWidth=390`，无被检测到的横向溢出；工作台宽度也未超出视口。
- CSV 绘图：通过实际 UI 发起持久任务，成功交付 PNG/PDF/Python；刷新深链接后事件仍可回放。`task-completed.png`。
- 私人资料：检索合成正文、引用打开原文件预览；不存在公开直链读取路径。
- 技能：点击示例“用 CSV 绘制趋势图”显示真实相关度和依赖顺序；星图旋转和技能选择。`skills-lab-desktop.png`。
- 图库：代码筛选+搜索“冲积图”得到 1 项；图卡说明和 Python 代码可展开；Escape 关闭后焦点回到原图卡入口。
- 拾景：实景拼贴/影像蒸馏可选，图像服务未配置时入口给出明确说明，未声称生成图片成功。

截图原件位于集成目录 `docs/audits/screenshots/`；本仓库保留部分脱离真实私人数据的验收图于 `docs/audit-screenshots/`。
