# Xinxin 前端规格

主人已确认：默认打开工作台概览，Agent 是独立一级入口。单主人、无公开注册；Android APK + PWA，优先保证核心功能。

首页提供实际任务、文件、技能、模型状态；主要操作进入 Agent。桌面侧边栏，手机工作台/Agent/任务/更多导航。任务展示真实过程、可下载产物；断线按游标恢复，重复提交复用请求标识。

每次对话选择只读/工作区/完整权限和服务器；说明完整权限含后端主机命令。模型与 SSH 密钥只发送给后端配置接口，不在前端环境变量持久化。切换后端清除认证，远程只支持 HTTPS。

保留文章、合集、相册、诗词、简历和管理。文章富文本、私人图片、合集关联；简历技能/经历/证书/头像/桌面打印。文件上传、检索、预览、下载、删除；服务器登记和编辑；技能检索与说明；记忆可编辑删除；自动化可编辑暂停删除。

工具页提供 CSV 绘图和 gathered-scenes-zine 图片转换；图片转换为次级入口，实景拼贴/影像蒸馏可选；缺图像服务显示配置提示。DeepSeek 负责对话，图片另配服务。

视觉：暖白底、深灰文字，一次一种可切换强调色，严谨网格、大标题、留白、细线、克制圆角和轻缓交互；不用堆叠渐变或炫技动画。层级清晰、键盘可用、响应式、安全区域、减少动效。

10 分：Agent、技能、任务恢复、服务器运维、手机安装包。代码/知识库9分，绘图/记忆/个人内容/自动化8分；学习出题明确排除，音乐暂不实施。先本地，后续再部署；两仓库严格独立。

补充：技能中心保留可拖动的月球能力星图；真实技能节点与列表均可操作，减少动态偏好下不自动旋转。图库支持搜索/结构/代码筛选与图卡详情。会话支持搜索、改名、归档和恢复；背景与交互保持暖白和单强调色。

邮箱验证码用于单主人登录和找回密码，设置页可配置 QQ SMTP。未配置授权码明确说明不可用，不模拟发送成功。服务器和 SMTP 授权尚未准备，后续验收；允许完成后推送指定两个仓库。
