# 公开进度、续接、批量删除与记忆交互

2026-10-18，基线后端6b7ea8e、前端5a543b3。主人手机测试后要求仅改善本批交互，不扩展其他产品功能。

1. 聊天穿插可理解的文字：说明已完成、现在做什么、接下来做什么。要求模型公开说明，平台同时提供真实工具阶段兜底，不把工具开始当成功。终端输出默认折叠可展开，信息不能全被日志淹没。无隐式思维链输出。
2. 长命令按实际目的、已运行时间、输出变化和日志线索解释等待；静默不能被猜成正在下载或卡死。每条命令等待提示有稳定标识、持久化/回放、限频并更新同一状态，后续回合可读。终态不得还显示运行中。内容先完整脱敏再取摘要，不额外调用模型制造心跳开销。
3. 预算耗尽后按钮直接续原任务：同会话/工作区、原始目标/附件和有效检查点，新的调用/用量/时间预算；前轮计数不叠加。每轮仍以本次明确选择的权限、服务器、记忆授权与上下文为准。只允许最新已结束轮次续接；幂等重试返回同轮，不能重复执行。过去步骤先核验，从未完成处推进，不盲重放命令；停止请求仍有效。
4. 批量永久删除：最近/归档列表可选择多个、全选筛选结果；清楚展示所选数量/名称及清理总量，统一确认。100段上限，拒绝空/重复/无效/不存在标识与活动任务；同一维护锁，全部SQL和文件暂存为一次事务，失败全回滚；只压缩一次。共享判断排除本批全部已选对话，保留任何未选对话/内容引用的文件和独立上传；不误删外部目录、凭据或服务器部署。物理清理失败如实返回pending。
5. 主人澄清是记忆授权勾选不可用。只读模式不再无解释禁用，开启前在同一处说明“勾选会切换为工作区，允许文件/记忆，不含系统命令”；明确勾选才更新下一轮选项，切回只读撤销记忆勾选。执行中不可变更当轮授权并解释原因。后端继续拒绝read+allow_memory，不访问/修改真实记忆作为测试。
6. 前后端独立改动；API契约通告新能力，旧服务不支持时明确提示升级，不悄悄丢参数。测试区分离线故障、浏览器、真实模型/SSH、实体手机。后端mattpocock两轴独立复验，前端BadGoods局部旅程检查；签名新APK，推送GitHub、空闲备份后更新原私有云服务。
