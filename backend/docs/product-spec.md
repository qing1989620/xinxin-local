# Xinxin 后端需求与验收规格

来源：主人在本会话中确认的问卷。首版只在本地实施，服务器部署另行指示。学习出题明确不需要；zhishi 只作研究。音乐低优先级，首版暂不实施。

1. 单主人账户，关闭公开注册。首次初始化需本地码；所有私人内容、文件、任务、技能、服务器配置要求认证。改密码使已有会话失效。
2. Agent 对话 10 分；手机发出任务，后端调用模型并执行。默认 DeepSeek V4.1 Flash 对应官方 API ID `deepseek-flash`，支持自填完整 API 地址、模型和密钥。缺配置必须提示，不伪装成功。
3. 技能调用 10 分。集成 SkillNet 的 BM25/向量融合与 shared LinUCB，保留依赖关系。相关度、授权、完成证据分开判断；反馈只接受已完成且有工具证据的任务，状态持久化。
4. 任务/日志/断线恢复 10 分。先持久化再执行，事件单调序号、游标回放、幂等提交、明确失败和取消。重启保留历史，未完标记中断，不自动重跑副作用。模型调用、时间和 token 有预算。
5. 服务器运维 10 分。私人登记服务器，凭据加密保存，SSH 校验已验证主机公钥。任务明确选择服务器；支持 GitHub Docker Compose 部署和健康核验，也可授权 SSH 分步处理其他项目。未经实际执行不得报告成功。
6. 权限像 Codex：每次任务选择只读、工作区、完整。只读不能写；工作区可创建任务文件、图表，不能执行系统命令；完整可操作后端主机和指定服务器。取消、超时停止本地受管进程。
7. 代码 9 分。任务工作区隔离，路径解析防越界；创建代码、执行授权命令、发布真实文件产物。私人文件/知识库 9 分：上传、下载、删除、解析文档、检索和文件引用。
8. 绘图 8 分。集成 Plot Is All You Need 的 95 张参考、样式卡、参考代码。快捷 CSV 绘图返回真实 PNG、PDF、脚本；复杂图由授权 Agent 读参考、写脚本、交付。
9. 记忆 8 分，主人可看、增、改、删；Agent 仅在获工作区权限且主人明确要求时写入。
10. 个人内容 8 分。保留 myself 文章、合集、相册、诗词、简历和管理；迁移保留图片、经历、技能、证书，不导入旧认证或密钥。数据在新的忽略目录中，不覆盖来源。
11. 自动化 8 分，固定间隔创建持久任务，可编辑、暂停、删除，每项保存权限和服务器。后端关闭期间不运行、不补跑历史。
12. gathered-scenes-zine 是次级工具和 Agent 工具，含实景拼贴/影像蒸馏。个人非商业技能单独安装；只向主人配置的图像服务发送所选图片，明确另需图像服务。
13. 后端仓库只放后端、Worker、适配、测试、文档；无兄弟源码 import 或运行时引用参考目录。密钥、数据库、上传和私人资产不提交。先本地，后续再部署。

14. 后续补充：主人邮箱验证码登录、找回密码，参考 lankhub；单主人边界保持关闭注册。SMTP 授权码后期提供，未配置必须明确不可用。6 位随机码，HMAC 持久化、10 分钟有效、60 秒冷却、最多 5 次错误、单次消费、持久发送配额；重置密码撤销旧会话。邮箱和 SMTP 授权加密保存在本地，不进入仓库。
15. 按 2 CPU / 4 GB 单人服务器准备部署文件；模型远程 API，不在服务器本地加载语言模型。默认任务并发 1，超出的排队。当前无云服务器、域名或 SMTP 授权码，只完成本地与部署准备；允许整理后推送指定 GitHub 仓库。

真实模型、图像和 SSH 验收需要凭据与环境；离线测试只证明协议、授权和本地工具。APK/PWA 和界面属于独立前端仓库。
