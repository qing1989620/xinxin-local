# cfd-simulation

> 领域：工程与仿真　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出网格无关的 CFD 结果并给出验证与不确定性

**输入**：几何模型；边界条件与物性参数；流动工况（雷诺数等）

**输出**：流场结果与云图；网格无关性验证；关键量收敛曲线

**适用时机**：
- 分析流动与传热
- 优化结构设计
- 验证实验与仿真的一致性

## 执行步骤

1. 简化几何并检查是否影响关键流动特征
2. 划网格并做网格无关性研究（至少三套网格）
3. 按雷诺数与可压缩性选湍流模型
4. 设置边界条件，检查质量与能量守恒残差
5. 做实验或解析解对比验证

## 常见陷阱

- 未做网格无关性验证
- 湍流模型选择与流动状态不匹配
- 边界条件设置产生非物理回流

## 验证清单

- [ ] 网格无关性已证明
- [ ] 残差收敛达标
- [ ] 守恒量残差检查通过
