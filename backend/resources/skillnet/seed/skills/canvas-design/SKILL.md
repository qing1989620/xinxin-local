# canvas-design

> 领域：设计与创意　|　来源：member-import（Nexus skills/canvas-design）　|　代际：G0

## 能力契约 / Capability

Create beautiful visual art in .png and .pdf documents using design philosophy. You should use this skill when the user asks to create a poster, piece of art, design, or other static piece.

**输入**：设计主题与参考意象；输出尺寸与格式要求

**输出**：PNG/PDF 视觉成品；设计说明

**适用时机**：
- 用户要求制作海报、视觉艺术作品或其他静态平面设计（.png/.pdf）时触发

## 执行步骤

1. Design Philosophy Creation (.md file)
2. Express by creating it on a canvas (.pdf file or .png file)
3. Form, space, color, composition
4. Images, graphics, shapes, patterns
5. Minimal text as visual accent
