# connectome-topology

> 领域：神经科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出网络拓扑指标并与随机基准做统计对比

**输入**：网络边列表（可含权重与方向）；节点属性；随机基准模型选择

**输出**：拓扑指标表；模块划分结果；统计对比结论

**适用时机**：
- 分析脑网络或蛋白互作网络
- 比较不同网络的组织差异
- 识别网络核心节点

## 执行步骤

1. 明确网络是否加权、有向，并做一致性检查
2. 生成匹配度序列的随机网络作为零模型
3. 计算聚类系数、特征路径长度、模块度
4. 用 σ = C/C_rand ÷ L/L_rand 判断小世界性
5. 识别核心结构与富人俱乐部并做统计检验

## 常见陷阱

- 用单一随机基准导致小世界性误判
- 忽略负边或自环
- 把模块度最大值当作唯一划分

## 验证清单

- [ ] 零模型选择已说明
- [ ] 指标以均值±标准差给出
- [ ] 核心结构检验已做
