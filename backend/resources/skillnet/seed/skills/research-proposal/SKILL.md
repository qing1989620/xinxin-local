# research-proposal

> 领域：基金申请与规划　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出结构完整、逻辑自洽、可评审的研究方案

**输入**：选题与研究问题；前期基础与预实验；经费与周期约束

**输出**：研究方案全文；技术路线图；进度甘特与预算表

**适用时机**：
- 撰写开题报告
- 申请科研基金
- 立项评审材料准备

## 执行步骤

1. 用一段话讲清科学问题与它的重要性
2. 拆成 3-4 个递进的具体目标，每个目标有可检验的判据
3. 为每个目标配技术路线、所需数据与替代方案
4. 写明前期基础与预实验结果作为可行性证据
5. 补齐进度安排、风险预案与预算明细

## 常见陷阱

- 目标过大无法在一个周期内验证
- 技术路线缺少备选方案
- 可行性缺少预实验支撑

## 验证清单

- [ ] 目标可检验
- [ ] 技术路线覆盖每个目标
- [ ] 风险预案可执行
