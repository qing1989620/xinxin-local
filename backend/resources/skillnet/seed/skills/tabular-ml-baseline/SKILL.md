# tabular-ml-baseline

> 领域：机器学习与人工智能　|　来源：seed　|　代际：G0

## 能力契约 / Capability

在表格数据上产出可信的预测基线并给出误差归因

**输入**：清洗后的特征表与目标变量；评估协议与划分方式；计算资源约束

**输出**：基线模型与性能表；特征重要性；误差分析报告

**适用时机**：
- 需要预测某个连续或类别目标
- 为复杂模型提供对照基线
- 评估特征的信息量

## 执行步骤

1. 先用线性/树模型建立不可再简化的基线
2. 按特征类型做编码与缺失指示变量
3. 用固定划分与固定随机种子保证可比
4. 做误差分布分析：哪类样本误差最大
5. 输出模型、特征重要性与适用边界

## 常见陷阱

- 在划分前做特征标准化造成泄漏
- 用测试集反复调参
- 只报单一指标掩盖子群性能差距

## 验证清单

- [ ] 划分与随机种子固定
- [ ] 基线可用简单模型复现
- [ ] 子群性能差异已报告
