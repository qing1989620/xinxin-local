# crystal-structure-predict

> 领域：材料科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出候选晶体结构并给出稳定性评估

**输入**：化学式或成分；可选结构搜索方法；计算资源约束

**输出**：候选结构文件；能量-结构对应表；稳定性评估结论

**适用时机**：
- 需要预测晶体结构
- 验证已知结构
- 寻找亚稳相

## 执行步骤

1. 用组成约束枚举或采样候选结构
2. 做结构弛豫并记录收敛判据
3. 按形成能与凸包距离排序筛选
4. 对候选做声子谱或弹性常数检查动力学稳定性
5. 与数据库已知结构比对避免重复发现

## 常见陷阱

- 不做动力学稳定性检查导致选出不稳定相
- 采样空间不足遗漏稳定结构
- 忽略有限温度效应

## 验证清单

- [ ] 弛豫判据已记录
- [ ] 凸包距离已计算
- [ ] 与数据库比对已做
