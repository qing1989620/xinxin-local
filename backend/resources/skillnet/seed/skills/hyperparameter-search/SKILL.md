# hyperparameter-search

> 领域：机器学习与人工智能　|　来源：seed　|　代际：G0

## 能力契约 / Capability

在给定预算内完成可复现的超参搜索与显著性比较

**输入**：搜索空间定义；评估协议；计算预算（GPU 小时/试验数）

**输出**：最优超参与配置；搜索轨迹；性能提升的置信区间

**适用时机**：
- 需要系统调优模型
- 比较不同模型在同等预算下的表现

## 执行步骤

1. 定义有物理意义的搜索空间与先验分布
2. 用贝叶斯优化或 Hyperband 在预算内搜索
3. 对每组配置重复多次运行以估计噪声
4. 用统计检验判断提升是否显著
5. 记录全部试验以便复现

## 常见陷阱

- 用单次运行结果比较配置
- 搜索空间包含无意义区间浪费预算
- 在测试集上做模型选择

## 验证清单

- [ ] 搜索轨迹与最优配置已保存
- [ ] 提升幅度给出置信区间
- [ ] 测试集未参与选择
