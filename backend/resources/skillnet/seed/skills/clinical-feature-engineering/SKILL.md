# clinical-feature-engineering

> 领域：临床与健康科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

构造无泄漏的可解释临床特征并支持跨患者验证

**输入**：病历与检查数据；时序检验结果；患者标识与时间戳

**输出**：特征表与特征字典；跨患者验证协议；特征可解释性说明

**适用时机**：
- 用电子病历做预测建模
- 需要临床可审计的决策依据

## 执行步骤

1. 按患者而非样本做数据划分
2. 构造聚合与趋势类时序特征但严格用预测时点前的数据
3. 处理不同检验项目的缺失模式
4. 对特征做临床合理性检查
5. 用跨患者协议评估模型并报告子群表现

## 常见陷阱

- 按记录而非患者划分导致同患者泄漏
- 使用未来检验结果
- 忽略测量单位与检验方法差异

## 验证清单

- [ ] 划分按患者分组
- [ ] 特征仅用预测时点前数据
- [ ] 特征单位与口径已写入字典
