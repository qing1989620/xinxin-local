# md-simulation

> 领域：蛋白质组学与结构生物学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

完成可复现的 MD 模拟并给出体系稳定性与关键指标分析

**输入**：初始结构（PDB）；力场与溶剂模型；温度、压力与时长设置

**输出**：平衡后的轨迹文件；RMSD/RMSF/Rg 曲线；关键相互作用分析

**适用时机**：
- 需要考察构象动态
- 验证对接结果的稳定性
- 计算结合自由能

## 执行步骤

1. 加氢、补缺失原子并确定质子化状态
2. 选力场、水模型与盒子尺寸，加抗衡离子中和
3. 做能量最小化与 NVT/NPT 分阶段平衡
4. 检查温度、密度、能量是否收敛再进入产出阶段
5. 分析 RMSD/RMSF/氢键并做多重复以确保可重复

## 常见陷阱

- 平衡未收敛就开始采样
- 只用单次模拟下结论
- 盒子过小导致周期性自相互作用
