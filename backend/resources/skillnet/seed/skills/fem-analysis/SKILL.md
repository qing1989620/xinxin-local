# fem-analysis

> 领域：工程与仿真　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出收敛且经过验证的有限元分析结果

**输入**：几何与材料参数；载荷与边界条件；设计许用值

**输出**：应力应变云图；安全系数；网格收敛性说明

**适用时机**：
- 结构强度校核
- 优化构件尺寸
- 评估失效风险

## 执行步骤

1. 简化几何并明确简化的合理性
2. 选本构模型并核对材料参数来源
3. 施加约束防止刚体位移，检查支反力平衡
4. 做网格收敛性研究并关注应力集中区加密
5. 与解析解或实验对比验证

## 常见陷阱

- 约束不足导致刚体位移
- 应力集中区网格过粗
- 材料参数与工况温度不匹配

## 验证清单

- [ ] 支反力与外力平衡
- [ ] 网格收敛性已证明
- [ ] 安全系数已对照许用值
