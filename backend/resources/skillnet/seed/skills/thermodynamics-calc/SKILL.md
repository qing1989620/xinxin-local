# thermodynamics-calc

> 领域：化学、药物发现与药理学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出反应热力学量、平衡常数与温度依赖关系

**输入**：化学体系或反应式；温度（默认 298.15 K）；可选动力学数据

**输出**：标准热力学量；平衡常数；范特霍夫图

**适用时机**：
- 判断反应能否自发
- 计算平衡常数
- 估算活化能

## 执行步骤

1. 配平反应式并核对各物质标准生成量
2. 按生成焓与熵计算反应焓变与熵变
3. 用 ΔG = ΔH - TΔS 计算吉布斯自由能
4. 由 ΔG 求平衡常数并绘制 lnK-1/T 图
5. 与文献实验值对比并说明偏差来源

## 常见陷阱

- 混淆标准态条件
- 忽略温度对焓熵的依赖性
- 把热力学可行等同于动力学可行
