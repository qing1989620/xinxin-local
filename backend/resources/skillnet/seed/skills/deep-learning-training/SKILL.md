# deep-learning-training

> 领域：机器学习与人工智能　|　来源：seed　|　代际：G0

## 能力契约 / Capability

把神经网络训练到稳定收敛并诊断常见失败模式

**输入**：数据集与任务定义；可选模型结构；算力与显存约束

**输出**：训练脚本与配置；训练曲线与诊断结论；最佳权重

**适用时机**：
- 需要训练神经网络
- 训练损失不下降或不稳定
- 需要提升现有模型性能

## 执行步骤

1. 先用小数据子集过拟合验证管线正确性
2. 确定批大小、学习率范围并用学习率扫描定位合理区间
3. 加入预热与余弦衰减策略
4. 按验证集曲线判断过拟合/欠拟合并对应调整
5. 固定随机种子并保存最佳权重与配置

## 常见陷阱

- 不做小样本过拟合检查导致管线有 bug
- 学习率过大掩盖梯度问题
- 按测试集调超参

## 验证清单

- [ ] 小样本可过拟合
- [ ] 训练曲线收敛无异常震荡
- [ ] 配置与权重可复现
