# eda-profiling

> 领域：数据与分析　|　来源：seed　|　代际：G0

## 能力契约 / Capability

系统性刻画数据集的分布、关系与质量风险

**输入**：清洗后的数据表；分析目标与分组变量

**输出**：EDA 报告；分布与相关性图组；候选特征清单

**适用时机**：
- 需要理解数据结构
- 为建模做特征初筛
- 分析前评估数据是否支持研究问题

## 执行步骤

1. 先做单变量分布与缺失率排行
2. 做分组对比，检查组间基线是否可比
3. 计算相关矩阵并标注共线性高的特征对
4. 检查目标变量的分布与类别不平衡程度
5. 输出候选特征清单与需要进一步处理的风险项

## 常见陷阱

- 只看均值不看分布形态
- 用相关系数解释非线性关系
- 忽略分组间样本量差异

## 验证清单

- [ ] 分布图覆盖全部关键变量
- [ ] 共线性项已标注
- [ ] 风险项有具体处理建议
