# arxiv-monitor

> 领域：文献与研究　|　来源：seed　|　代际：G0

## 能力契约 / Capability

对新增预印本做增量筛选与要点摘要

**输入**：关键词或作者列表；上次追踪时间戳；相关性阈值

**输出**：新增相关论文列表；每篇三行要点摘要；趋势提示

**适用时机**：
- 需要持续跟进领域前沿
- 组会前准备最新进展
- 为综述做增量更新

## 执行步骤

1. 按关键词与作者抓取指定时间窗内新增预印本
2. 与历史记录去重，只保留未处理条目
3. 按标题与摘要做相关性打分并过滤
4. 对通过筛选的论文生成三行要点：问题/方法/结论
5. 汇总本周趋势与被多次引用的新方法

## 常见陷阱

- 重复推送已读论文
- 仅凭标题判断相关性
- 摘要失真的过度解读

## 验证清单

- [ ] 新增条目与时间窗一致
- [ ] 去重后无重复
- [ ] 要点摘要与摘要原文一致
