# materials-screening

> 领域：材料科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

在预算约束下产出按多目标排序的候选材料清单

**输入**：候选材料库；目标属性与约束阈值；可验证的实验预算

**输出**：候选排序清单；不确定性估计；推荐实验批次

**适用时机**：
- 需要挑选少量候选做验证实验
- 多目标（性能-稳定性-成本）权衡

## 执行步骤

1. 明确目标与硬约束，区分必须满足与偏好项
2. 用代理模型预测属性并估计不确定性
3. 用采集函数选择同时兼顾高预测与高不确定的候选
4. 检查候选是否落在训练分布外并标注风险
5. 按批次给出可执行的实验建议

## 常见陷阱

- 只按预测值排序忽略不确定性
- 筛选条件过于严格导致无候选
- 忽略合成可行性

## 验证清单

- [ ] 排序含不确定性
- [ ] 候选在适用域内或已标注风险
- [ ] 推荐批次包含探索项
