# signal-processing

> 领域：工程与仿真　|　来源：seed　|　代际：G0

## 能力契约 / Capability

从时序信号中提取无混叠、无泄漏的频谱与时频特征

**输入**：原始时序信号；采样率与量程；目标频段与噪声特性

**输出**：滤波后信号；功率谱/时频图；提取的特征表

**适用时机**：
- 分析生理或机械信号
- 去噪并提取频域特征
- 为分类模型准备信号特征

## 执行步骤

1. 确认采样率满足奈奎斯特并检查是否已混叠
2. 去趋势与去工频干扰
3. 选窗函数与重叠率以平衡频率分辨率与泄漏
4. 做时频分析定位非平稳段
5. 提取时域、频域与时频域特征并说明含义

## 常见陷阱

- 采样率不足导致混叠不可逆
- 窗函数选择不当造成频谱泄漏
- 滤波引入相位失真未做零相位处理

## 验证清单

- [ ] 采样与混叠情况已说明
- [ ] 窗函数与重叠率已记录
- [ ] 滤波为零相位或已补偿
