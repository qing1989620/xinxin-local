# citation-verify

> 领域：文献与研究　|　来源：seed　|　代际：G0

## 能力契约 / Capability

逐条核验引用的真实性与表述一致性，剔除无法验证的引用

**输入**：带引用的文稿；参考文献列表；可访问的检索接口

**输出**：核验报告（通过/存疑/错误）；修正后的参考文献列表

**适用时机**：
- 投稿前终检
- 综述或报告交付前
- 怀疑存在模型伪造引用

## 执行步骤

1. 抽出全部引用标记与对应参考条目
2. 通过 DOI 或数据库检索确认条目真实存在
3. 核对年份、作者、期刊、卷期是否一致
4. 回到原文确认被引结论与本文表述一致
5. 对无法核验的引用标记为存疑并要求替换或删除

## 常见陷阱

- 仅凭题名相似就判定引用正确
- 直接信任模型生成的参考文献
- 忽略预印本与正式版本的差异

## 验证清单

- [ ] 每条引用都有可访问标识（DOI/arXiv ID）
- [ ] 存疑项已单独列出
- [ ] 修正后编号连续无断号
