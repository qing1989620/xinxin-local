# statistical-testing

> 领域：数据与分析　|　来源：seed　|　代际：G0

## 能力契约 / Capability

为研究设计选择正确的检验并给出完整的统计报告

**输入**：指标数据与分组变量；实验设计说明；显著性水平与检验方向

**输出**：检验结果表；效应量与置信区间；统计方法说明段

**适用时机**：
- 需要比较组间差异
- 论文中报告统计结果
- 需要判断结果是否稳健

## 执行步骤

1. 先判断设计类型：独立/配对、组数、是否正态
2. 对正态假设做检验并给出不满足时的非参数替代
3. 计算效应量而不只报 p 值
4. 多重比较时使用 FDR 或 Bonferroni 校正
5. 报告检验统计量、自由度、p 值、效应量与置信区间

## 常见陷阱

- 对非正态数据强行使用 t 检验
- 只报 p 值不报效应量
- 多重比较未做校正导致假阳性

## 验证清单

- [ ] 检验前提假设已验证
- [ ] 效应量与置信区间齐备
- [ ] 多重比较已校正
