# literature-review

> 领域：文献与研究　|　来源：seed　|　代际：G0

## 能力契约 / Capability

从研究问题出发完成 PRISMA 式检索-筛选-抽取-综合，产出带证据链的文献综述

**输入**：研究问题（建议 PICO 格式）；检索年限与语言范围；可用数据库清单

**输出**：综述初稿；筛选流程数量台账；结构化证据抽取表；BibTeX 文献库

**适用时机**：
- 需要梳理某方向的研究现状
- 为选题或立项做背景调研
- 论文引言缺少系统证据支撑

## 执行步骤

1. 把研究问题拆成概念矩阵并列出同义词
2. 在 3 个以上数据库执行可复现的检索式并记录命中数
3. 按纳入/排除标准做标题-摘要与全文两轮筛选，逐级记录数量
4. 逐篇抽取设计/样本/方法/结论/局限到结构化表
5. 按主题聚类做综合论证，显式标注证据强度与结论冲突

## 常见陷阱

- 只检索单一数据库造成覆盖偏差
- 把综述写成文献罗列而无综合论证
- 引用未做 DOI 或原文核验

## 验证清单

- [ ] 检索式与各轮命中数可复现
- [ ] 筛选流程图数字自洽
- [ ] 每条引用可回溯到 DOI 或原文
