# data-cleaning

> 领域：数据与分析　|　来源：seed　|　代际：G0

## 能力契约 / Capability

把原始数据转为可分析数据集，并记录每一步清洗决策

**输入**：原始数据文件；字段说明与业务规则；缺失与异常的判定阈值

**输出**：干净数据集；清洗审计日志；数据字典

**适用时机**：
- 拿到未经处理的原始数据
- 合并多个来源的数据表
- 发现数据质量异常

## 执行步骤

1. 先做结构与类型探查，确认主键唯一性
2. 标记缺失模式，区分随机缺失与非随机缺失
3. 用业务规则而非纯统计阈值识别异常值
4. 对每步处理记录原因、影响行数与前后分布
5. 产出数据字典说明每个字段的口径与单位

## 常见陷阱

- 直接删除缺失行导致选择偏差
- 用均值填补非随机缺失
- 静默修改数据不留痕迹

## 验证清单

- [ ] 清洗后主键唯一
- [ ] 审计日志可复现每一步
- [ ] 关键字段分布变化有解释
