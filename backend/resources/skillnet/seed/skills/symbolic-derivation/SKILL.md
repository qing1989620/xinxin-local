# symbolic-derivation

> 领域：数学与建模　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出经过数值交叉验证的符号表达式

**输入**：待推导的数学表达式或方程；变量与假设条件；需要验证的数值点

**输出**：解析表达式；化简结果；数值一致性验证

**适用时机**：
- 需要解析解
- 推导理论公式
- 验证数值方法的解析基准

## 执行步骤

1. 明确变量定义域与假设条件
2. 做符号推导并保留中间步骤
3. 在若干数值点比对符号解与数值解
4. 检查边界与奇点行为
5. 输出可直接用于代码的表达式

## 常见陷阱

- 忽略定义域导致结果在部分区间失效
- 不做数值验证
- 化简过度丢失约束条件

## 验证清单

- [ ] 数值交叉验证通过
- [ ] 边界行为已检查
- [ ] 假设条件已显式声明
