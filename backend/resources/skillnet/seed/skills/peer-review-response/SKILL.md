# peer-review-response

> 领域：学术写作与可视化　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出逐条回应信与修改对照表，覆盖每条意见

**输入**：审稿意见原文；修改前后文稿；补充实验数据

**输出**：逐条回应信；修改位置映射表；修订版文稿

**适用时机**：
- 收到返修意见
- 需要与审稿人沟通方法分歧
- 需要补充实验回应质疑

## 执行步骤

1. 把每条意见拆成可独立回应的原子问题
2. 分类为：接受并修改 / 解释澄清 / 礼貌反驳 / 补充实验
3. 每条回应给出具体修改位置与行号
4. 对需要新实验的意见安排优先级与可行性
5. 统一语气：感谢-回应-证据-修改位置

## 常见陷阱

- 只回复部分意见或回避关键质疑
- 反驳缺少证据支撑
- 未标注修改位置导致审稿人重复阅读

## 验证清单

- [ ] 每条意见都有对应回应
- [ ] 回应中的修改位置可在文中定位
- [ ] 反驳意见附有数据或文献证据
