# paper-deep-read

> 领域：文献与研究　|　来源：seed　|　代际：G0

## 能力契约 / Capability

逐节拆解论文并产出可复用的方法卡与局限清单

**输入**：目标论文 PDF；希望回答的具体问题

**输出**：方法与实验设置摘要；可复用技术点清单；局限与未解问题清单

**适用时机**：
- 需要复现某篇论文的方法
- 需要判断某方法能否迁移到自己的问题
- 写相关工作章节

## 执行步骤

1. 先读摘要-图-结论建立全局判断，再回读方法与实验细节
2. 提取数据集、基线、评价指标、随机种子等可复现要素
3. 区分作者主张与实验支持的实际结论
4. 识别消融实验覆盖了哪些组件、遗漏了哪些
5. 输出方法卡：适用条件、代价、失败模式

## 常见陷阱

- 把作者的宣称当成已验证结论
- 忽略附录中的实验细节与负结果
- 混淆相关性与因果性表述

## 验证清单

- [ ] 关键数字与原文一致
- [ ] 方法卡能指导他人复现
- [ ] 局限清单至少包含实验未覆盖项
