# lightcurve-analysis

> 领域：天文学与空间科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

从时序测光数据中检出周期与暂现信号

**输入**：时序测光数据与误差；观测波段与采样；已知星体目录

**输出**：周期图与最优周期；光变分类结果；候选信号列表

**适用时机**：
- 搜索周期变星
- 检测凌星候选体
- 分析暂现源光变

## 执行步骤

1. 做系统误差校正与相邻点合并
2. 用 Lomb-Scargle 或相位折叠搜索周期
3. 评估周期显著性并检查谐波混淆
4. 用相位折叠可视化验证周期
5. 对候选信号做人眼复核与已知目录比对

## 常见陷阱

- 采样窗口造成混叠假周期
- 忽略系统误差导致的虚假信号
- 只用单一方法确证信号

## 验证清单

- [ ] 混叠与谐波已检查
- [ ] 显著性已量化
- [ ] 与已知目录比对已做
