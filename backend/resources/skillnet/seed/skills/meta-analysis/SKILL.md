# meta-analysis

> 领域：临床与健康科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

综合多项研究的效应量并评估异质性与偏倚风险

**输入**：检索到的研究集；各研究的效应量与样本量；偏倚风险评估工具

**输出**：合并效应量；森林图与漏斗图；异质性与偏倚分析

**适用时机**：
- 多项研究结论不一致
- 需要给出定量综合结论
- 系统综述的定量部分

## 执行步骤

1. 制定预先设定的纳入排除标准并注册方案
2. 提取效应量并统一为同一尺度
3. 按固定或随机效应模型合并，检验异质性 I²
4. 做亚组分析与敏感性分析定位异质性来源
5. 用漏斗图与 Egger 检验评估发表偏倚

## 常见陷阱

- 事后修改纳入标准
- 存在异质性仍用固定效应模型
- 忽略小样本研究的偏倚
