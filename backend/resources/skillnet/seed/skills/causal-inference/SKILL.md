# causal-inference

> 领域：数据与分析　|　来源：seed　|　代际：G0

## 能力契约 / Capability

在观察性数据上构造可信的反事实并估计处理效应

**输入**：处理变量、结果变量与协变量；可用的外生变异来源；样本量与时间结构

**输出**：平均处理效应估计；平行趋势/平衡性检验；敏感性分析

**适用时机**：
- 需要评估干预效果
- 观察性数据上做因果结论
- 政策或实验效果评估

## 执行步骤

1. 用 DAG 显式写出假设的因果结构
2. 识别混杂变量并检验协变量平衡
3. 选择识别策略：匹配/加权/DID/IV/RDD 并说明其假设
4. 做安慰剂检验与平行趋势检验
5. 对未观测混杂做敏感性分析并报告稳健区间

## 常见陷阱

- 控制处理后的变量导致过度控制偏差
- 平行趋势不成立仍用 DID
- 把统计显著等同于因果有效

## 验证清单

- [ ] 因果图假设已显式声明
- [ ] 识别假设已通过检验
- [ ] 敏感性分析给出结论稳健范围
