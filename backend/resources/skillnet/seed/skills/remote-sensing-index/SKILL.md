# remote-sensing-index

> 领域：生态与环境科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出经过质量控制的时间序列植被指数与趋势结论

**输入**：遥感影像或指数产品；时间范围与研究区边界；云掩膜与质量控制波段

**输出**：时序指数数据；物候参数（SOS/EOS）；趋势与显著性结果

**适用时机**：
- 分析植被动态
- 提取物候参数
- 评估生态恢复效果

## 执行步骤

1. 做云影与雪掩膜，统计无效像元比例
2. 统一不同传感器间的辐射定标
3. 合成时序并做平滑与缺口填补
4. 提取物候指标并检查异常年份
5. 用趋势检验评估变化显著性并做空间制图

## 常见陷阱

- 忽略不同传感器的系统性偏差
- 平滑参数掩盖真实突变
- 用固定阈值提取物候忽略区域差异
