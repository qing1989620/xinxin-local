# frontend-design

> 领域：设计与创意　|　来源：member-import（Nexus skills/frontend-design）　|　代际：G0

## 能力契约 / Capability

Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. Helps with aesthetic direction, typography, and making choices that don't read as templated defaults.

**输入**：产品定位与目标用户；设计参考

**输出**：有辨识度的界面设计方案

**适用时机**：
- 构建新 UI 或改造现有界面，需要独特有辨识度的视觉设计与排版方向时触发

## 执行步骤

1. a near-black background with a single bright acid-green or vermilion accent;
2. a broadsheet-style layout with hairline rules, zero border-radius, and dense newspaper-like columns;
3. Color: describe the core base palette as 4–6 named hex values
4. Type: the typefaces and their roles
5. Principles: the high-level guidance for what makes this page unique
