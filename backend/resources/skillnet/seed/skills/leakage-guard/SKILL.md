# leakage-guard

> 领域：机器学习与人工智能　|　来源：seed　|　代际：G0

## 能力契约 / Capability

识别并消除会导致乐观偏差的数据泄漏路径

**输入**：特征表与目标变量；数据采集与划分时间线；预处理流程代码

**输出**：泄漏审计报告；修正后的管线；修正后性能对比

**适用时机**：
- 模型指标高得不合理
- 需要保证评估可信
- 投稿前的方法学自检

## 执行步骤

1. 逐特征追问「该信息在预测时点是否可获得」
2. 检查是否存在同时期的代理特征
3. 检查划分是否按时间或按个体分组
4. 检查预处理是否在全量数据上拟合后拆分
5. 定位重复样本与近重复样本并去重

## 常见陷阱

- 把处理后数据当作特征
- 随机划分时序数据
- 在全量数据上做特征选择后再划分

## 验证清单

- [ ] 每个特征有可获得性说明
- [ ] 划分方式与数据结构匹配
- [ ] 去重后指标重新报告
