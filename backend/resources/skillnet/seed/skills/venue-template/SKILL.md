# venue-template

> 领域：学术写作与可视化　|　来源：seed　|　代际：G0

## 能力契约 / Capability

把内容装配成符合目标期刊模板的终稿并完成格式合规检查

**输入**：正文与图表源文件；目标 venue 模板与投稿须知；BibTeX 源

**输出**：可编译的终稿 PDF；格式合规检查清单；投稿材料包

**适用时机**：
- 准备投稿
- 需要按模板排版
- 返修后重新套版

## 执行步骤

1. 选用官方最新模板并确认版本号
2. 按模板要求迁移章节、图表与参考文献样式
3. 编译检查是否存在溢出、缺图、引用未定义
4. 核对页数、图表数量、摘要字数等硬性限制
5. 打包终稿、补充材料与图片源文件

## 常见陷阱

- 使用过期的模板版本
- 图表使用了位图导致印刷模糊
- 补充材料超出大小限制

## 验证清单

- [ ] 无编译警告与未定义引用
- [ ] 页数与图表数符合限制
- [ ] 图件为矢量或高分辨率
