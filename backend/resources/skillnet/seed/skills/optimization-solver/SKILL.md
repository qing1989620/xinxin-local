# optimization-solver

> 领域：数学与建模　|　来源：seed　|　代际：G0

## 能力契约 / Capability

把业务问题转化为可求解的数学规划并给出敏感性结论

**输入**：决策变量与目标；约束条件与参数；问题规模与求解时限

**输出**：优化模型与求解结果；对偶变量与敏感性；可行性诊断

**适用时机**：
- 资源分配与调度
- 参数寻优
- 需要最优性证明

## 执行步骤

1. 明确决策变量、目标函数与约束的数学形式
2. 判断问题类别（LP/MILP/NLP）并选求解器
3. 检查模型可行性与数值尺度问题
4. 求解并检查最优性间隙与求解状态
5. 做参数敏感性分析说明结论的稳健范围

## 常见陷阱

- 建模时遗漏实际约束导致方案不可执行
- 数值尺度过差导致求解失败
- 把启发式解当作全局最优

## 验证清单

- [ ] 求解状态为最优或给出间隙
- [ ] 模型与业务约束逐条对应
- [ ] 敏感性分析已给出
