# flux-tower-ml

> 领域：生态与环境科学　|　来源：seed　|　代际：G0

## 能力契约 / Capability

产出防泄漏的碳通量预测模型与跨站迁移能力评估

**输入**：通量站观测数据（如 FLUXNET）；气象驱动因子；站点元数据

**输出**：GPP 预测模型；时空分离评估结果；驱动因子响应曲线

**适用时机**：
- 预测生态系统碳吸收
- 分析气象因子影响
- 评估模型跨站点泛化

## 执行步骤

1. 合并站点数据并统一时间分辨率与单位
2. 构造气象、地理与干旱指数特征
3. 做时间留出与留一站交叉验证两套评估
4. 对比树集成与线性模型的迁移能力差异
5. 用 PDP/ICE 分析驱动因子响应并检查是否符合生态学预期

## 常见陷阱

- 随机划分造成时间泄漏
- 只看时间留出性能高估泛化
- 忽略站点间分布差异

## 验证清单

- [ ] 时间与空间两套评估均已报告
- [ ] 特征构造无未来信息
- [ ] 响应曲线符合机理预期
