## 发现与处置

| 级别 / 问题 | 证据和影响 | 修复及验证 |
| --- | --- | --- |
| P1 填空匹配丢失学科含义 | 基线删除标点、空格与大小写差异，可能把小数、正负号、区间和代码字符串判为同一个答案 | 精确字符匹配及有界分数运算；覆盖 `1.2/12`、区间开闭、括号优先级、字符串空格、大小写和精确数值等价 |
| P1 多空答案被分隔符误拆 | 单空区间含逗号、代码字符串含分号；旧格式还可能吞空位 | 逐空输入和答案数组，保留旧客户端兼容，拒绝缺答及错误数组类型；桌面、手机从输入到持久化实际验证 |
| P1 答案正确但解析错误仍通过 | 真实样本中单调方向写反，同模型加强提示后仍沿用同一错误 | 先隐藏答案独立求解，再对照两份解答；解析步骤单独检查，单选结论冲突程序拒绝。保留真实漏审反例，不宣称形式化验证 |
| P2 原题补题反复消耗额度 | 隔离真模型补题两次返回 6 个既有候选，全部被去重，未进入审题 | 从模型原题清单中直接剔除已入库项，并反馈重复原因；原题目标按实际完整新题调整 |
| P2 片段页段过大，无法小范围验证 | 稳定文字片段可能跨十几页，原页读取最多 24 页但缺少片段内起止页选择 | 精读范围、预览、页预算、缓存、复核及补题使用同一物理页段；覆盖逆序、越界、重叠页、部分阅读和范围改变 |
| P2 失败缩批不能恢复题量 | 临时失败后批量永久缩到一题，剩余尝试次数不足以达到计划 | 成功批次逐步恢复；合成回归验证 3→1→2→3 后仍完成 12 题 |
| P2 待核对结果没有清楚的恢复路径 | 服务失败、格式错误及未配置模型需要区分知识错误 | 原作答以 unknown 保存，总结排除待核对项；结束后可原位重判，不重复计数、不替换原答案 |
| P2 草稿和辅导上下文易混淆 | 切题、刷新、切模式以及主动讲解时需保留不同未发输入；旧题辅导曾不区分练习 | 分层草稿键、成功匹配才清除、旧请求保护、当前会话辅导与只读旧记录；未作答不返回标准答案和带答案引文 |
| P2 导入恢复后书架不刷新 | 恢复中的识别任务完成，但已加载书架保持旧列表 | 完成快照触发书架及统计刷新；迟到快照和取消响应增加身份保护，防止覆盖新状态 |
| P2 测试与桌面共用构建产物 | 浏览器构建可覆盖 `frontend/dist`，而正在运行的后端仍是旧源码版本 | 测试使用 `.qa-data/preview-dist`，原生测试使用专属目录；启动器验证自定义输出目录边界，原生测试断言主人 index 字节未变 |
| P3 公式命令重复转义 | 真模型填空答案出现双反斜杠，影响显示与本地匹配 | 对普通公式检测重复转义，保留矩阵及多行结构；复核请求中填空答案使用真正数组，避免第二层 JSON |
| P2 审查发现：旧草稿实例覆盖新内容 | 两轴均以纯内存复现：离开再回来后旧实例清理整张旧字典，新追问和另一题草稿丢失 | 每次操作读取当前共享存储，按匹配值清理并合并其他草稿；退出登录使旧内存缓存失效；新增真实 SPA 离页、返回、迟到响应及刷新恢复回归 |
| P2 审查发现：引文边界绕过去重 | 同一原题的旧引文不带题号，新引文带题号，字符串比较视为两题 | 服务端保存完整原题规范证据，无歧义精确包含映射旧引用；集成验证计划归零且不调用生成，数学条件变化不误合并 |
