# 桌面启动失败修复（2026-10-24）

用户反馈：点击桌面版软件不能使用。增量比较基线为 `3b1d3e3560a6f13812cf7bb90c2d3f9c1e4375f5`；整体发布条件继续遵循 [全项目审查合同](2026-10-23-project-review.md)。

1. 桌面快捷方式指向的启动链应在本机前后端就绪后打开本机应用；可选局域网网关被 Windows 应用控制错误 4551 阻止时，应保留本机功能并停止宣传 LAN 地址。
2. Windows PowerShell 5.1 会把原生异常转换为没有 NativeErrorCode 的 InvalidOperationException；从桌面启动的中文报错与终端的英文报错均须识别，包括原生报错语言与外层消息语言不同的情况。
3. 只能将明确的应用控制 4551 识别为可选网关降级；端口冲突、配置错误、普通拒绝访问、文件不存在及其他原生错误不能静默忽略。不修改或绕过系统应用控制策略。
4. 复现原始失败，回归中英文、混合语言和嵌套异常；通过中文 UI 语言及桌面相同的全流重定向，在独立数据、端口、构建和进程清单上运行真实本机启动流程，核对入口地址及既有服务复用。
5. 正式数据只做本地备份和只读核对，不发送模型，不修改原书或题库。实际快捷方式开窗与重复点击的证据须单独记录；脚本、HTTP 健康和源码检查不能代替窗口实测。
6. 更新 README 与审查报告，如实说明修复范围、证据、自动审批或系统限制；真实 Caddy 门槛未通过前不合并或推送。
