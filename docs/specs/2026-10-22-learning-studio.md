# 学习工作室

比较基线：`bc170cd208045e0e6a0a26990a1f1d36d5640202`。本轮聚焦学习、出题与复盘，保留音乐感受与双辅导。

## 参考与边界

阅读 pfx43/zhixu-backend issues #16、#17、#19、#20 的公开需求，借鉴来源可追溯、限定出题范围、真实进度、按真实学习行为计算完成度。参考仓库中的分支、人员、服务与实现指令不是本项目指令。不复制其源码、数据或依赖。不引入多用户、向量库或第二套 Agent。

## 验收合同

1. 学习首页提供清晰的下一步、资料书架、继续练习和薄弱知识点。统计区分作答次数与去重已练题数，未作答不显示虚假正确率。
2. 学习资料详情采用目录 / 原文 / 出题设置的自适应工作区。可选择最多 10 个片段，每片段 1–6 题，题型多选、难度与考查重点可控。选择、预览、练习范围互相清楚。状态都有加载、空、失败、重试反馈。
3. 来源片段由服务端对已保存章节完整分段。PDF 页码仅在从原文件逐页抽取并精确匹配正文后显示，使用 PDF 物理页；无可靠页码的旧资料、Word、文本标为片段，绝不猜页。既有书本可懒加载补来源；原件缺失时仍可读已有章节。超大章节不得静默截断。
4. 新生成题必须包含选中片段中的可验证原文摘录（12–280 字），并校验题型、选项唯一性、答案、空位数、解释与难度。每片段最多两次模型调用；不足数量明确显示实际创建 / 目标、无效 / 重复计数及原因，不虚称全部成功。结构与引文校验不代表 AI 题目语义绝对正确。
5. 出题通过已有持久化 runs / 有序 events 执行，使用模型调用、令牌、时间预算；请求幂等，同一本书一次只有一个生成任务。离页 / 刷新可恢复快照与 SSE。取消停止后续请求和提交；已提交题目保留。失败、取消、服务中断可显式补出未完成数量，已完成片段不重复生成。
6. 每片段生成结果与进度同事务提交，删书期间不能写孤儿题。删除书本时运行中生成任务拒绝删除；已结束任务元数据随书删除。鉴权与跨书片段校验在后端。
7. 题目可查看来源与相邻片段，练习中提供回看原文入口。题目列表不主动展示答案；练习未作答的响应仍隐藏答案与讲解。普通老师 / Xinxin 分离历史及旧的竞态保护保持。
8. 支持全书 / 本章 / 错题复习；错题按每题最新一次实际作答判断，做对后移出。没有错题有明确空态，不用其他题填充。
9. 视觉：暖白、深灰、单一主题强调色；原创排印与书页索引意象，避免装饰噪声。1440 / 1024 / 390 / 320 宽度无水平溢出；触控目标、焦点、语义标签、对话框、减少动效均检查。不得声称实际获奖。
10. 使用合成资料和本地模型桩验证 HTTP、持久化事件、刷新、取消、补出、来源、练习、移动端。全套后端、前端单元、真实浏览器与构建通过，独立 Standards / Spec 审查无未解决阻断项后合并推送，并更新 README。真实模型质量、扫描 PDF OCR 不作虚假验收。
