## 已定位与修复

| 问题 | 证据与影响 | 修复与复验 |
| --- | --- | --- |
| P1 一条坏引用否决整个片段 | 经授权真实模型复现：同段有许多有效逐字引用，同时含改写的引用；旧解析器遇到第一条失配即停止，尚未进入出题 | 服务器编号关联原文、逐条跳过坏项、超上限保留可校验部分；零有效结果最多重试一次；回归覆盖混合坏项、37 条清单和全无证据 |
| P1 文字 OCR 丢失数学条件 | 对照用户原页与本地提取结果，原图分式/上下标清晰而 OCR 缺条件；普通 OCR 的成功不代表数学正文完整 | 明确可选的 PDF 原页读取，按 3 页小批读取，独立转录与缓存，审题再次附原图；原文件、原 OCR 和旧题保留 |
| P2 输出截断导致整段终止 | 小范围真实模型检查出现大批复核输出截断 | 每批改为最多 3 题；发生模型输出错误或审题错误时继续受限缩批；目标总题量仍为每片段 1～24 |
| P2 完整短题被字符阈值拒绝 | 两道完整合成数学题合计不足 80 个非空白字符，旧规则在分析之前拒绝 | 编号练习最低 24 字，保留普通知识 80 字门槛；UI 使用后端可选性；仍须来源和独立审题通过 |
| P2 修复旧失败任务时读取方式未更新 | 原补题逻辑始终继承旧任务所有选项，无法显式改用原页理解；省略新字段的旧客户端又需要保留原方式 | 补题可明确改变读取方式，沿用旧目标与已提交进度；省略方式时保持旧选择；界面按实际补题范围显示原页数量和限制 |
| P2 长段落没有可用的短证据位置 | 独立 Spec 审查用 900 字单物理行复现：整行超过知识证据 800 字上限 | 长行拆为最多 400 字的连续编号片段；展示、解析与原页映射共用切分，无损拼接；覆盖跨片段与跨页引用 |
| P2 短题导入路径和编号格式不一致 | Standards 审查发现 UI 的持久化导入仍要求 200 字；Spec 审查发现括号编号未被识别 | 导入与建书共用最低长度；识别中英文括号题号；新增从上传、持久化导入到分析、出题、复核的合成短题回归 |
| P2 部分原页失败被摘要缓存挡住重试 | Spec 审查指出：一页可读、一页失败仍保存摘要，后续直接复用摘要而不重读失败页 | 仅完整原页分析可以直接复用；回归验证首次读取 1、2 页、第二次仅读取失败的第 2 页、第三次完整缓存不再调用 |
| P3 跳过条目总数没有展示 | Spec 审查发现只展示原因，未渲染 `skipped_entries` | 摘要折叠栏展示跳过总数；上限改按有效条目计数，覆盖前 30 条坏引用而第 31 条有效的组合 |

## 边界与恢复

原页预览要求主人鉴权，仅可读取所属来源范围，响应禁止缓存，不触发模型。单个来源最多 24 页、单任务最多 60 页，转录每组最多 3 页；取消后保留已经完成的页缓存。图片在后端有界渲染，不暴露宿主路径；引用、页码与识别方式随题目保存，未作答时仍隐藏答案及带答案的依据。

当前修复保留本地供审核，不自动再次推送。桌面实际运行版本、完整测试与两轴独立审查结果在完成后补录。
