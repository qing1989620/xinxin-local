# 手机连不上？按这三步定位

绝大多数「连不上」都出在第 2 步。

## 第 1 步：电脑上的服务还活着吗

打包（gradle）会吃掉大量内存，**可能把正在运行的服务挤掉**。每次打包后请重新执行：

```powershell
./Start-Xinxin-Local.ps1
```

看到 `backend ready` / `frontend ready` / `gateway ready` 三行才算起来。确认端口：

```powershell
foreach ($p in 8010,5180,8080) {
  $c = Get-NetTCPConnection -LocalPort $p -State Listen -ErrorAction SilentlyContinue
  if ($c) { "$p 监听中" } else { "$p 未监听" }
}
```

浏览器打开 <http://127.0.0.1:5180> 能出界面，就说明后端和前端都活着。

## 第 2 步：防火墙放行了吗（最常见的原因）

手机访问电脑的 8080 端口属于**入站连接**，Windows 防火墙默认拦截。**必须管理员权限运行一次**：

```powershell
./Setup-Lan-Access.ps1
```

脚本会探测局域网 IP、自动请求管理员提权（弹 UAC），创建入站规则「Xinxin本地版网关 (TCP 8080)」，最后打印手机地址。

手动等价命令（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "Xinxin本地版网关 (TCP 8080)" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Any
```

验证规则是否存在：

```powershell
Get-NetFirewallRule -DisplayName "Xinxin本地版网关 (TCP 8080)" | Select-Object DisplayName,Enabled,Direction
```

### 顺带检查网络位置

网络位置是「公用」时，Windows 会更严格地拦截入站连接。查看当前类别：

```powershell
Get-NetConnectionProfile | Select-Object Name,InterfaceAlias,NetworkCategory
```

若是 `Public`，建议改成专用（同样需要管理员）：

```powershell
Set-NetConnectionProfile -InterfaceAlias "WLAN" -NetworkCategory Private
```

`InterfaceAlias` 换成上一条命令实际显示的网卡别名。

## 第 3 步：手机和电脑真的在同一网段吗

- 电脑：启动日志里打印的 `http://<局域网IP>:8080`
- 手机：连同一个 Wi-Fi。**访客网络 / AP 隔离**是常见坑，两端虽然同一个 SSID 但互相不通
- 公司 / 校园网常做**客户端隔离** → 用手机开热点、电脑连这个热点验证，能通就说明是网络策略问题

## 还是不行

1. 电脑浏览器开 <http://127.0.0.1:8080>：能出登录页说明网关正常
2. 手机浏览器开 <http://电脑IP:8080>：
   - 浏览器能出登录页、APK 不行 → APK 里的地址不对，去 app 设置页改，或清理 APK 数据重装
   - 浏览器也打不开 → 回到第 1、2 步，八成是服务没起来或防火墙没放行
3. 看网关日志：`logs/caddy-access.log`、`\.runtime\gateway.err.log`
