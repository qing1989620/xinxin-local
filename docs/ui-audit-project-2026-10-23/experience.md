# 全项目优化后的体验与效果

本轮保留暖白纸面、深灰文字和单一强调色，沿用已经统一的导航、标题、列表、表单与窗口。重点是让同一套界面在网络抖动、快速切换、取消和删除时也保持可靠。本文说明功能能达到的行为；实际验收状态以 [主报告](review.md) 为准。

| 使用场景 | 优化后的行为 | 验证边界 |
| --- | --- | --- |
| 手机通过普通 HTTP 打开本地应用 | 上传、连续 Agent 任务、学习导入可生成稳定请求标识；同一不确定提交重试可继续使用原身份 | 在 Edge 的真实不安全 HTTP 上下文验证，后端为隔离本机实例；原生网关仍须恢复运行许可 |
| 刚重新登录时收到旧请求的 401 | 旧 API、图片下载、上传和任务流不会清掉新身份；旧流不会带新身份重连 | 会话代际回归覆盖四类传输；不改变服务器权限校验 |
| 初次进入 Agent 或恢复取消任务时配置很慢 | 发送和继续按钮等待配置就绪；读取失败时保留输入草稿，直接重新读取；就绪后一次点击发送或续接 | 8项桌面/手机尺寸延迟与503测试；续接检查原任务端点、同一会话、补充要求及恰好一次提交 |
| 模型或工具回显凭据 | 当前值与运行期间保留的旧值共同参与过滤；完整有效 JSON 解码后脱敏，普通多行引文仍过滤，截断的引号尾部保守隐藏；中文进度持续显示 | 覆盖三种引号状态、多块切分、轮换及正常/断流落库；连续 ASCII token 和引号内容可能等待后再显示，损坏尾部不会原样公开 |
| 永久删除生成资料的对话 | 仍被学习书或其他内容使用的原件会保留；专属 OCR、提取缓存和预览随原件清理，失败回滚 | 并发预览与删除互斥；已下载副本、浏览器缓存及按保留周期存在的备份不属于本次删除范围 |
| Agent 生图后查看交付 | 图像登记在本轮任务下，可在交付中找到；取消时等待受管请求收尾，取消后不再登记迟到文件 | 已发出的外部请求不能撤回；本轮使用合成供应方验证导入和生命周期 |
| 出题包含代码或字符串 | 内部双空格、代码缩进、换行保留，题干哈希也保留这些差异 | 本轮新增语义空白回归；真实数学质量依据此前授权的 30 次验收，未新增收费调用 |
| 初次设置时误输入中文初始化码 | 返回清楚的拒绝响应，不再变成服务器异常 | 正确初始化、重复初始化和未授权访问一并验证 |
| 启动、停止或添加隧道入口 | 只处理本项目记录且身份匹配的进程；隧道不再重启正在工作的后端；自定义上游端口写入网关配置和指纹 | 原生生命周期测试与真实 Caddy 运行分开；不修改 Windows 安全策略 |

学习仍按“材料识别 → 选择范围/校对 → 理解知识与完整原题 → 分批生成 → 独立求解和解析复核 → 入库练习”进行。资料不足、目录、残缺题或无法核对的答案会给出原因，保留已通过的题，不以无关题目凑数量。原题模式受完整新题数量约束；知识拓展模式可在证据支持范围内补充。每片段 12 题是默认值，可以调节，任务恢复仅补缺少的题。此前改进及对原项目的比较见 [学习体验总结](../learning-experience-2026-10-23.md)、[真实验收](../learning-live-acceptance-2026-10-23.md)、[源码对照](../zhishi-learning-comparison.md)。

老师与 Xinxin 辅导保持相同知识约束，分别保存历史与草稿。未作答时先给切入提示；作答后可讲解、追问及查看函数图。主观判分不可用时保留原答并显示待核对，可以对原作答重判。

SkillNet 的价值仍在每轮工作中可见：选择了什么方法、为什么选、是否实际读取参考、哪些关联工具成功返回，以及最终交付在哪里。候选排名、读取和执行结果分别呈现；技能相关性不会自动授予执行权限。

全站复核覆盖桌面、窄屏、键盘操作、减少动态效果、长内容与延迟响应。实体手机输入、读屏、真实邮件送达和远程 SSH 等外部条件保留明确的未验证记录。不能把本机合成链路通过等同于所有真实教材、模型回答和外部服务均不会出错。

可预期的改善是：普通HTTP入口具备提交能力，慢配置不再造成首次点击无动作，旧请求不打断新登录，取消、清理和恢复有可核对的状态。学习能按可读证据分批补题、保留正确题与作答，失败可解释并可继续；实际题目数量受完整原题与知识证据限制，不以凑够数量代替正确率。原生网关许可恢复前，这些局域网旅程仍只有隔离HTTP验证，不能宣称手机网关已恢复。
