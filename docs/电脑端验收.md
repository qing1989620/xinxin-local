# 电脑软件端 · 验收记录

对 `desktop/` 电脑软件端的一次完整验收（2026-10-19）。目标：确认桌面端像普通软件一样可用——双击图标自动就绪、独立应用窗口、单实例、错误可诊断。

## 验收项与结果

| # | 验收项 | 方法 | 结果 |
| --- | --- | --- | --- |
| 1 | 停止服务后网关无监听 | `-Stop` 后查 8080 端口 | 通过（0 listeners） |
| 2 | 端口被占用时弹错误窗口 | 占住 8010/5180/8080 再启动 | 通过：启动器退出码 1，生成错误窗口 |
| 3 | 错误窗口内容完整 | 检查 `desktop-error.html` | 通过：含占用端口说明、换端口命令 `GatewayPort`、完整日志路径 |
| 4 | 日志编码干净 | 检查 `.runtime/desktop.log` | 通过：中文正常，无 UTF-16 乱码行 |
| 5 | 冷启动开应用窗口 | 停止后重新启动 | 通过：24s，单窗口，`/health` 200 |
| 6 | 单实例 | 服务在跑时再次启动 | 通过：激活已有窗口，不重复开窗 |
| 7 | VBS 无窗口入口 | 日志 `console=False` | 通过 |
| 8 | 安装快捷方式 | 装到桌面 + 开始菜单 | 通过：`Xinxin.lnk`、`停止 Xinxin 服务.lnk` |
| 9 | 卸载快捷方式 | 删除快捷方式 | 通过（沙箱把个人目录删除转回收站，真实机器不受影响） |
| 10 | 启动日志不重复 | 连续两次冷启动对比 | 通过（修复后） |
| 11 | 桌面窗口隐藏安装提示 | 截图检查顶栏 | 通过：无「安装到手机」按钮，`?desktop=1` + sessionStorage 生效 |

## 本轮修复的两个缺陷

| 缺陷 | 原因 | 修复 |
| --- | --- | --- |
| 错误窗口没有日志路径，用户不知道去哪看全文 | 模板只放了日志尾部 | `error-template.html` 加 `{{LOGPATH}}`，启动器写入 `.runtime/desktop.log` 绝对路径 |
| 启动日志里 `start\|` 行重复出现两次 | `*>>` 是追加写，捕获文件 `desktop-start.log` 累计历史内容又被整体搬进日志 | `Start-LocalStack` / 停止逻辑先删掉捕获文件再写 |

## 涉及文件

- `desktop/Xinxin-Desktop.ps1` — 启动器（清空捕获日志、错误页补日志路径）
- `desktop/assets/error-template.html` — 错误窗口模板（加日志路径段落）
- `frontend/src/App.tsx` — `?desktop=1` 标记持久化到 `sessionStorage`
- `docs/电脑端.md` — 文档同步（错误窗口描述补全）

## 未做 / 不在范围内

- 未接入云端、不涉及 APK / 手机端改动。
- 沙箱对「个人目录递归删除」有硬拦截，卸载/清理只在 workspace 内验证过；真实机器行为以脚本逻辑为准。
- 没有做打包成 MSI / 安装器，仍是「脚本 + 快捷方式」形态（这是一贯的设计约束，见 `docs/电脑端.md`）。
