## 设计与检查范围

29 个页面或独立子视图，覆盖身份、初始化、离线、导航和页面搜索、13 个一级功能、内容五个分栏、技能三个视图、音乐三个分栏、教材与练习详情、404、桌面启动和错误窗口。组件区域的内部按钮、字段、提示和装饰纳入该区域契约；不将每条重复记录计为独立组件。细节以 [audit.json](audit.json) 中 PAGE / DEF / CMP / SCN / CHK 为准；初始检查为 `not_checked`，实际验证后更新。

共享 `polish.css` 管理暖白、深灰、强调色、字号、留白、边线、圆角、控件和断点，功能样式管理专业布局。共享 `Dialog` 保留原生 top layer / inert，负责输入焦点、关闭回落、按下和松开都在背景时关闭、忙碌期间保护；通知在当前模态内呈现。表单使用字段组禁用而非仅禁用保存按钮，防止请求期间新编辑被响应覆盖。按路由加载较重模块，入口不必下载编辑器和学习渲染器。

## 已确认的修复方向

- 基线设置页在 390px 溢出 88px、320px 溢出 158px；用可收缩网格、字段组和窄屏布局修复，待最终全量复验记录。
- 资料正文搜索缺少请求所有权；新查询取消旧请求，正文读取失败提供重试。
- 任务失效详情只有 spinner、断流未接权威快照；增加详情错误和快照恢复。
- 技能与歌单详情读取可被旧响应覆盖；对读取、关闭和切换设置取消/所有权。
- 记忆、自动化、内容、工具和歌单等创建操作增加同步提交锁、忙碌反馈；工具上传及富文本配图完成前保护表单。
- 共用弹窗默认焦点落在关闭按钮、外部 toast 被 native top layer 遮挡；输入焦点和模态内错误提示进入回归。
- 生图输入法确认 Enter 不再触发生成；退出请求失败仍清除本机会话并明确服务器撤销未确认。

## 证据与边界

浏览器仅访问隔离 8017 后端与 5187/5197 前端，使用合成主人、内容和资料；真实 CRUD、队列与接口使用项目后端。模型由固定离线传输替身驱动，错误和乱序场景使用明确的 HTTP 替身。没有读取主人数据库、聊天记录或私密文件，也没有执行真实 SSH、发送邮件或付费图像请求。

当前定向 10 项桌面/手机用例通过，覆盖全局搜索、保存失败及重试、七类入口弹窗、技能子视图与迟到详情、音乐键盘和歌单关闭。此前新增内容 CRUD、搜索与任务恢复等 19 项通过；首次全量视觉检查和焦点检查发现问题的记录保留在本机。最终计数以本报告后续验证表为准，不能把重跑计数相加当作不同测试数量。

未验证：实体 iPhone/Android 软键盘和中文 IME、完整屏幕阅读器、所有浏览器组合、第三方音乐 CDN、真实模型的教学质量和 SSH/SMTP/Resend/付费图像服务的真实连通性。模拟 `isComposing` 只覆盖事件处理，不替代实体输入法验收。生产实验室测量不等于真实用户 p75 或 INP。
