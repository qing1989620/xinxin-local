# 学习真实链路：30 次专项验收

固定起点 `250e6fa9f615c152aeca51a86334ac8cfc9f8e78`，对应[本轮验收合同](specs/2026-10-23-learning-live-acceptance.md)。主人本轮明确授权最多 30 次 DeepSeek 调用，与此前 16 次额度分开记账。

本次继续检查「生成—隐藏答案独立求解—对照审题」，并通过实际 HTTP 接口执行持久化任务、补题、练习、主观判分和双辅导。所有测试结果放在忽略目录的隔离题库；本报告只记录统计与工程结论，不附原书、题目、截图、模型密钥或私人对话。

## 发现与修复

1. **生成格式冲突。** 原提示拼接了旧数组示例和新对象协议，真实补题曾返回超量题、缺少来源/类型字段，并出现长篇试错导致截断。改为单一对象协议，明确必填字段、数量及最终推导要求；保留程序校验和受限恢复。
2. **答案正确不代表解析正确。** 多轮真实反例表明，增加正确性标志、盲解或逐步提示仍可能漏审。某一中间版本甚至在盲解正确时批准了错误原句，不能算作通过。最终为官方 DeepSeek 学习请求启用推理模式，先推导再填写答案；审题先逐段检查、再给总评。已知错误解析最终被明确定位并拒绝，同批正确题通过。
3. **总体结论可能掩盖细节冲突。** 服务器拆分候选解析及简答参考要点，要求每段有唯一索引、布尔结论和核验依据；漏段、重段、无效依据均拒绝，一段失败不能被总评 accept 覆盖。单选不一致和可精确解析的填空数值冲突由程序直接拦截。
4. **辅导过早透露解题结果。** 真实老师提示曾把第一小问结论写入示例。未作答时现在不给模型参考答案、解析和来源摘录，并要求仅给一个切入点和一个问题。最终老师与 Xinxin 的真实提示均未公布最终结果；作答后正常提供完整核对。
5. **诊断也要隔离初始化。** HTTP 检查必须在导入 ASGI 模块前切换数据目录，避免模块级应用初始化接触正式库。已修正并增加无副作用导入回归；按原备份的共同字段逐行核对，原书、正式题库、作答、辅导正文、文件和配置均保留。旧备份缺少的辅导会话列属于此前已经完成的增量迁移。
6. **常见分数简写的冲突。** 独立 Spec 审查发现 `-\frac12` 不在旧数值解析语法内，审题模型错误批准时程序不能否决。现在有限支持两个单数字参数和单数字/花括号混合参数，保留符号、零分母、长度和指数限制；不把多余 TeX token 当作多位数字，也不引入通用公式求值。

学习专用推理涵盖生成、盲解、审题、主观判分及两种辅导，仅对已明确支持的官方 DeepSeek 接口启用。其他兼容服务维持原协议，普通 Agent 和音乐请求保持原有默认模式。返回及诊断记录只保留最终内容和显式核验依据，不保存提供方的内部推理字段。[官方推理接口说明](https://api-docs.deepseek.com/guides/thinking_mode/)支持此参数及计费令牌统计；启用推理可能增加等待和用量。

## 人工核对与体验结果

实际新增的 **5 道题**逐项对照相应 PDF 原页，复算条件、答案和关键步骤：原题部分包括充分必要条件判断、分式化简、对称配对求和；知识拓展包括递推数列渐近与对数积分型极限。未发现这五道题的结论或关键推导错误。另核对旧正确对照题，并确认旧错误解析的不等号和单调方向确实错误。人工核对与模型同意分别记录，后者不能替代前者。

这次可达到的效果是：两个原来失败的片段能产生有出处的可用练习，缺额可继续补出；老师先提示、作答后核对，Xinxin 保留陪伴表达且不降低数学标准；服务异常仍保留待核对状态、作答及追问草稿。原题模式不会凭空制造缺失原题，知识拓展另行标识，不把页码或章节位置当成学习内容。

本次是所选六个原页及相关旅程的小范围真实验收，并非全书或所有模型的数学证明。缺图、残缺条件、模糊公式和无法确认的步骤仍会阻止入库；通用符号代数等价、手写识别和真实手机硬件不在此次新增能力中。正式题库没有自动重审、删除或混入诊断题。

## 网关环境限制与桌面恢复

首次完整回归为 425 项通过、1 项失败。失败项为真实 Caddy 进程的 256 MiB 上传边界测试：Windows 在启动程序时返回应用控制错误 4551，尚未到达上传请求。单独只读版本检查也被相同策略阻止；没有将这一项改成已通过，也没有关闭、绕过或修改系统安全策略。

启动器现仅对可选 Caddy 的 4551 错误保留本机入口，继续显示前端和后端已就绪，明确提示手机/局域网暂不可用。其他权限、端口、配置或进程错误仍然报告失败；后端及前端仍只监听回环。本次验收继续覆盖本机学习，真实 Caddy 上传测试作为环境阻塞单独保留。

实机启动进一步发现 Windows PowerShell 5.1 的 Start-Process 会将原生错误展平成不含错误码及内部异常的 InvalidOperationException。定向测试原先只覆盖了保留错误码的包装形式，不能替代这一实际检查。兼容补丁仅增加此异常类型及实测完整应用控制消息的精确匹配；普通 Access is denied、配置失败仍不降级，补充回归 2 项通过。
