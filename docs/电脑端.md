# 电脑软件端

Xinxin 的第三个端：**像普通桌面软件一样用**。双击桌面上的 Xinxin 图标，自动就绪后打开一个独立的应用窗口——没有地址栏、没有标签页、没有浏览器菜单，就是「电脑里的一个软件」。

手机端、网页端、电脑端用的是**同一套本机服务**（同一个后端、同一份数据、同一个网关端口）。电脑端不新增任何服务器，也不改变其它端的行为。

---

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 一键就绪 | 服务没起时自动拉起（等价于 `Start-Xinxin-Local.ps1 -NoBrowser`），首次启动可能等一两分钟，期间有启动页 |
| 独立应用窗口 | Edge 应用模式：无地址栏 / 无标签页，独立配置目录，不污染日常浏览器 |
| 单实例 | 窗口已开着再双击图标，只是把已有窗口带到前台，不会开出第二个 |
| 会话持久 | 登录状态保存在电脑端自己的配置目录里，重启窗口不用反复登录 |
| 与手机/网页共存 | 关闭窗口**不会**停止服务，手机端和网页端继续可用 |
| 开机自启（可选） | 安装时加 `-AutoStart`，登录 Windows 后自动启动电脑端 |

## 安装（一次）

```powershell
# 在项目根目录
./Install-Xinxin-Desktop.ps1

# 或双击
安装电脑端.cmd
```

安装器只创建快捷方式，不复制代码、不构建任何东西：

- 桌面：`Xinxin`
- 开始菜单：`Xinxin本地版\Xinxin`、`Xinxin本地版\停止 Xinxin 服务`
- 加 `-AutoStart` 额外注册开机自启（写在「启动」文件夹，删掉快捷方式即取消）
- 加 `-Start` 装完立即启动一次

安装后双击桌面图标即可使用。

---

## 卸载

```powershell
./Uninstall-Xinxin-Desktop.ps1

# 或双击
卸载电脑端.cmd
```

只删除安装器创建的快捷方式（桌面、开始菜单、开机自启），不动项目代码和数据。

- `-RemoveProfile`：顺带清理电脑端会话（下次启动要重新登录）
- `-StopServices`：卸载前先停止本机服务

## 日常使用

| 场景 | 操作 |
| --- | --- |
| 打开 | 双击桌面 `Xinxin` 图标（或开始菜单里的同名项） |
| 窗口关了想再开 | 再双击一次图标；窗口开着时双击只会激活它 |
| 停止全部服务（手机/网页同时停） | 开始菜单 → `停止 Xinxin 服务` |
| 前台看日志 | `./desktop/Xinxin-Desktop.ps1 -Console` |
| 换窗口初始大小 | `./desktop/Xinxin-Desktop.ps1 -Width 1600 -Height 1000` |

日志在 `.runtime/desktop.log`；启动失败时会弹出一个错误窗口，附原因、日志尾部，以及完整日志的路径。

## 工作原理

```
双击图标
   │
   ▼
Xinxin-Desktop.vbs（无窗口入口）
   │
   ▼
Xinxin-Desktop.ps1
   ├─ 服务已在跑？ ──是──▶ 激活已有窗口 / 打开应用窗口 ──▶ 退出
   │                   否
   ├─ 拿启动锁（单实例，防重复拉起）
   ├─ 打开启动页（starting.html）
   ├─ 拉起本机服务（Start-Xinxin-Local.ps1 -NoBrowser）
   ├─ 轮询 /health 直到就绪
   ├─ 关掉启动页，打开应用窗口 http://127.0.0.1:8080/?desktop=1
   └─ 退出（服务继续在后台跑，手机/网页不受影响）
```

几个设计取舍：

- **不另起服务**：电脑端只做「确保服务就绪 + 开一个窗口」。端口、数据、鉴权全部复用现有链路，避免第二套状态。
- **应用窗口用 Edge 应用模式**：Windows 10/11 自带 Edge，零额外依赖；没有 Edge 时自动退回系统默认浏览器打开同一地址，功能不丢。
- **关闭窗口 ≠ 停止服务**：服务可能正被手机端使用。要停就用「停止 Xinxin 服务」。
- **`?desktop=1` 只是给前端的一个信号**：让应用窗口隐藏「安装到手机 / 离线就绪」这类只对网页端有意义的提示。不带这个参数时（网页、手机）行为与之前完全一致。

## 排障

| 现象 | 原因与处理 |
| --- | --- |
| 双击图标后只有启动页，很久不出现应用窗口 | 首次启动要建虚拟环境 / 装依赖 / 构建前端，属正常；看 `.runtime/desktop.log` 进度 |
| 弹出「这次没能启动」窗口 | 常见是端口被占用。换网关端口：`./Start-Xinxin-Local.ps1 -GatewayPort 8081`，或手动跑一次上面的命令看完整输出 |
| 窗口打开了但是登录页/白屏 | 服务可能刚被外部停掉；再双击一次图标会自动重拉服务并开新窗口 |
| 图标变了 / 窗口大小不对 | 删掉 `.runtime/desktop-profile`（会话目录）后重开 |
| 想彻底重来 | 卸载电脑端（`-RemoveProfile`），再重新安装 |

## 与其它端的关系

| 端 | 入口 | 说明 |
| --- | --- | --- |
| 电脑端 | 桌面 / 开始菜单图标 | 本文档；独立应用窗口 |
| 网页端 | `http://127.0.0.1:8080` | 本机或局域网浏览器，任意现代浏览器 |
| 手机端 | `http://<局域网IP>:8080` 或 APK | 同一服务；APK 见 README「手机」一节 |

三端共享同一份数据与账号；电脑端和网页端可以同时开着。
